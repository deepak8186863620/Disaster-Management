1. Deepak Prajapati Database Architecture, Cloud Firestore & Offline Cache
Primary Files: src/services/firebase.js | src/services/storageHelper.js

Key Concepts to Explain:

  • NoSQL Document Schema: Modular Firestore collections for disasters, sensors, sensorReadings, alerts, aiRecommendations, and citizenReports.
  • Persistent Offline Cache: When cell towers and internet connection drop during an emergency, Firestore keeps a multi-tab persistent cache in browser IndexedDB.
  • Resilient Storage Fallback (storageHelper.js): Seamless local persistence ensuring zero data loss if network drops.

Code to Highlight:

// src/services/firebase.js
db = initializeFirestore(app, {
  localCache: persistentLocalCache({
    tabManager: persistentMultipleTabManager()
  })
});

In natural disasters, communication towers frequently collapse. To guarantee uninterrupted operations, I implemented Firestore's multi-tab offline persistence alongside a local cache fallback. Our NoSQL schema allows instantaneous real-time updates between officers and field responders with zero data loss."

3. Nishanth IoT Sensor Telemetry Grid & Open-Meteo REST APIs
Primary Files: src/services/sensorService.js | src/pages/SensorMonitoringPage.jsx

Key Concepts to Explain:

  • IoT Telemetry Grid: Real-time monitoring of hydrological gauges, Doppler rain meters, marine anemometers, and seismic sensors.
  • Automated Anomaly Detection: Differentiates valid high readings from anomalous equipment glitches (e.g., river surge > 15m).
  • Live Open-Meteo Integration: Real-time HTTP queries fetching global river discharge (m³/s) and atmospheric temperatures (°C).

Code to Highlight:

// src/services/sensorService.js
async fetchLiveOpenMeteoFlood(latitude = 59.91, longitude = 10.75) {
  const url = `https://flood-api.open-meteo.com/v1/flood?latitude=${latitude}&longitude=${longitude}&daily=river_discharge`;
  const res = await fetch(url);
  const data = await res.json();
  const currentVal = data.daily?.river_discharge[0];

  return await this.ingestReading({
    sensorId: "sensor-hyd-01",
    sensorName: "Live River Basin (Open-Meteo)",
    type: "water_level",
    value: Number(currentVal.toFixed(2)),
    unit: data.daily_units?.river_discharge || "m³/s"
  });
}
Speaking Script for Nishanth: "I was responsible for the IoT Sensor Subsystem and external meteorological integrations. We monitor real-time hydrological and seismic readings. Furthermore, we integrated Open-Meteo's live global APIs for live river discharge and atmospheric temperatures to validate hazard trends against official international feeds."

Code to Highlight:

// src/services/alertService.js
async createAlert({ title, message, severity, affectedAreas, channels }) {
  const newAlert = {
    id: `alert-${Date.now()}`,
    title,
    message,
    severity,
    affectedAreas: Array.isArray(affectedAreas) ? affectedAreas : [affectedAreas],
    channels: channels || ["push", "sms", "radio"],
    status: "active",
    createdAt: new Date().toISOString()
  };
  return await this.saveAlert(newAlert);
}

// src/context/AuthContext.jsx
export const hasRole = (allowedRoles = []) => {
  if (!currentUser) return false;
  if (currentUser.role === "admin") return true; // Superuser override
  return allowedRoles.includes(currentUser.role);
};
